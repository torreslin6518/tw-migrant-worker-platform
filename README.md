# 台灣移工媒合平台

這是一個簡單的台灣移工媒合平台前端範例，目標是：
- 提供越南、印尼、馬來西亞勞工了解台灣工作選擇
- 整理熱門職缺資訊與薪資範圍
- 展示可信的台灣仲介公司服務
- 提供申請流程與常見問題說明

## 瀏覽方式

1. 在專案根目錄開啟 `index.html`
2. 或使用本地靜態伺服器，例如：
   ```bash
   python -m http.server 8000
   ```
3. 開啟瀏覽器進入：
   ```text
   http://localhost:8000
   ```

## 內容特色

- 首頁介紹平台定位與獲得資訊的優勢
- 工作機會區塊，可依國家與職業類別篩選
- 仲介公司區塊，重點展示合法協助服務
- 申請流程與 FAQ 區塊，方便勞工快速了解
- 使用純 HTML / CSS / JavaScript，方便修改與擴展

## 可擴展方向

- 加入後端資料庫與管理後台
- 增加多語言版本（中文、英文、越南文、印尼文）
- 串接實際勞工招募與仲介公司資料
- 建立求職表單與聯絡功能
- 加上登入與後台管理畫面

## 建議技術延伸

若想往正式網站邁進，可擴展成：
- Next.js + TypeScript
- Tailwind CSS
- Supabase / PostgreSQL
- Vercel 部署
